# Remotion Video

Programmatic, data-driven video in React with Remotion. For developers and motion designers building React compositions and rendering them to MP4 or GIF — via the CLI or `@remotion/renderer`, including headless per-record templating.

## When it activates

- "Make a video with Remotion" or "create a programmatic / data-driven video in React"
- "Render an MP4 / GIF from code"
- "Animate with useCurrentFrame / interpolate / spring" or "sync video to audio / beats"
- "Render a templated video per record headlessly"

## Example prompts

- "Build a Remotion composition and render it to a 1080p MP4 from the CLI."
- "Animate this scene with useCurrentFrame and spring, synced to the audio track."
- "Render one templated MP4 per row of this CSV, headlessly."

## What's inside

- `SKILL.md` — when to use it plus composition and rendering workflow.
