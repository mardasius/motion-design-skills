# Motion Design Skills

> Motion design fundamentals, engines, and brand elements as installable skills for AI coding agents — timing, typography, color, composition, After Effects, Remotion, logos, and backgrounds.

## Install

```bash
npx skills add iart-ai/motion-design-skills
```

Works with Claude Code, Cursor, Codex, GitHub Copilot, and 40+ agents.

## What's included

| Skill | What it does |
| --- | --- |
| [motion-principles](./motion-principles) | Tech-agnostic timing, easing, and the 12 principles for natural-feeling motion. |
| [typography-motion](./typography-motion) | Kinetic typography and text reveals in CSS, GSAP, Framer Motion, and Remotion. |
| [color-motion](./color-motion) | Palettes, gradients, perceptual interpolation (OKLCH/Lab), grading, and render color management. |
| [shot-composition](./shot-composition) | Grids, safe areas, focal hierarchy, and 2D/3D camera framing across aspect ratios. |
| [motion-direction](./motion-direction) | Senior creative direction — motion language, tone, pacing, hierarchy, and restraint. |
| [after-effects](./after-effects) | AE expressions, rigging, export recipes, performance triage, and project hygiene. |
| [beat-sync-editing](./beat-sync-editing) | Cut to the beat — editing rhythm, transitions, retiming, and speed ramps. |
| [remotion-video](./remotion-video) | Programmatic, data-driven video in React rendered to MP4/GIF via CLI or renderer. |
| [logo-animation](./logo-animation) | Logo reveals, stingers, splash screens, and loaders for web, video, and app. |
| [motion-background](./motion-background) | Mesh gradients, shader auroras, particle constellations, and subtle looping backgrounds. |

## When it activates

- You ask to fix, time, or polish how something moves (stiff, floaty, robotic, snappy).
- You're animating text, logos, or backgrounds for the web, video, or an app.
- You're building or rendering video programmatically with Remotion or working in After Effects.
- You're directing the overall look — pacing, color, composition, and consistency.
- You're editing a sequence to music or planning shot rhythm.

## Example prompts

- "Make this animation feel natural — it looks robotic and stiff."
- "Build a kinetic typography video with a staggered split-text reveal."
- "Animate our logo into a 3-second brand intro with a sound-logo sync."
- "Create a data-driven video in Remotion that renders one MP4 per CSV row."
- "Add a subtle looping mesh-gradient background behind the hero."
