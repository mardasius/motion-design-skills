# Beat Sync Editing

Editing rhythm for motion designers and editors — cutting to the beat, transitions, retiming, and speed ramps. Translates an edit plan into an NLE or a code timeline (Remotion / After Effects frames).

## When it activates

- "Cut to the beat" or "sync cuts to music / BPM"
- "Fix the pacing" or "edit this sequence"
- "Add a match cut / J-cut / L-cut"
- "Build a speed ramp" or "plan a shot sequence / edit timeline"

## Example prompts

- "Cut this sequence to the beat at 128 BPM and give me the frame numbers."
- "The pacing drags — fix it and add a match cut between these two shots."
- "Build a speed ramp into the drop and turn the plan into Remotion frames."
