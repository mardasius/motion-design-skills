# Shot Composition

Frame composition for motion designers — grids, safe areas, focal hierarchy, and 2D/3D camera framing. Helps you decide where elements live, where they enter and exit, and how a layout adapts across aspect ratios.

## When it activates

- "Compose a frame", "set up a grid", or "plan shot composition"
- "Place the focal point" or "decide where elements enter and exit"
- "Add a parallax / camera move"
- "Adapt a layout for 16:9 / 9:16 / 1:1" or "keep content inside safe areas"

## Example prompts

- "Compose this frame on a grid and place the focal point with clear hierarchy."
- "Adapt this 16:9 layout to 9:16 and 1:1 while keeping everything in the safe areas."
- "Add a subtle parallax camera move as the elements enter."
